# Contoso Thailand Workplace Agent-a-thon — Web App v4

This version includes a separate `config.js` file.

## Files
- `index.html`
- `styles.css`
- `config.js` ← edit this for the resource-folder link
- `app.js`
- `README.md`

## Configure the resource link
Open `config.js` and replace:

```js
resourceFolderUrl: "PASTE_YOUR_RESOURCE_FOLDER_LINK_HERE"
```

with your SharePoint / OneDrive participant resource folder URL.

Keep `index.html`, `styles.css`, `config.js`, and `app.js` in the same folder when testing or hosting.

Language options:
- EN
- ไทย
- EN + ไทย

The wording is neutral so the challenge can be run individually or in teams.
